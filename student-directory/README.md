# Student Directory - Next.js App Router

A beginner-friendly Student Directory web application built with Next.js App Router, TypeScript, and Tailwind CSS.

## Features

- Student directory listing with responsive grid cards
- Instant case-insensitive search by student name
- Department filter with count indicators
- Dynamic student profile routes (/students/[id])
- Academic records and course enrollment breakdown
- Clean empty states and 404 fallback page

## Tech Stack

- Next.js (App Router)
- React
- TypeScript
- Tailwind CSS

## Getting Started

Install dependencies:

```bash
npm install
```

Run the development server:

```bash
npm run dev
```

Open [http://localhost:3000](http://localhost:3000) in your browser.

## Build and Test

```bash
npm run build
npm run lint
```
